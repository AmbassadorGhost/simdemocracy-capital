# SimDemocracy: The Capital

A VRChat world for r/SimDemocracy: a civic square at dusk with a courtroom, legislative
chamber, president's office, the Queer Quorum café, the Secretary Name National Archives,
a cinema, and a suspicious side room.

Unity 2022.3.22f1 with VRChat Worlds SDK 3.10.5. Open it through VRChat Creator Companion,
which restores the SDK packages from `Packages/vpm-manifest.json`. The current scene is
`Assets/SimDemocracy/Scenes/SimDemocracy-Capital-v07.unity`; start with `START-HERE.md`.
