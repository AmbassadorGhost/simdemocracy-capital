# SimDemocracy: The Capital

This is the Unity project prepared from the official VRChat Worlds template,
with VRChat Base and Worlds SDK **3.10.5** and the SimDemocracy world assets.

Open it from Creator Companion using **Unity 2022.3.22f1**. License activation
has been confirmed and the editor now runs.

Open `Assets/SimDemocracy/Scenes/SimDemocracy-Capital-v07.unity` for the latest
scene: a working synced cinema, dusk sky and windows, the fountain and timeline,
the presidents wall and desk drawers, a witness stand, pickup mugs, an optional
café mirror and the full Constitution in the archives. See `V07-NOTES.md`.
`V06-WALKTHROUGH.md` and `V05-MEMES.md` cover the earlier passes.
The earlier scenes are preserved.
Unity C# and Udon compilation and scene wiring checks have passed. Next run
the VRChat SDK's validation tools and Windows Build & Test.
Use **SimDemocracy → Build Starter Scene** only to generate another fresh scene;
it does not preserve manual changes in that new scene and creates the earlier
v0.2 blockout. The v0.7 scene is already built; do not regenerate to open it.

The source overlay and detailed feature/testing notes are in the adjacent
`SimDemocracy-v0.2/SimDemocracy-Starter` folder. The adjacent
`SimDemocracy-Capital-v0.2.zip` is the portable source package.

This world has not been uploaded. Cinema playback is wired but untested in VRChat;
final art and PC/Quest multiplayer acceptance testing remain unfinished.
